轉職背景帶來的工作習慣

把文件和紀錄當成產出的一部分

行政工作讓我重視流程、資料整理與文件完整度。寫程式後，延伸成對 README、CHANGELOG、版本紀錄和測試可重現性的要求。

先拆角色與資料，再開始切版

多角色系統先釐清權限與資料流，再決定元件與狀態怎麼切。Mock／真實 API 切換機制，讓前後端不用互相等待。

用 AI 加速，但每個結果都自己確認

AI 用在測試規劃、案例產生與失敗分析，最後是否採用由我判斷，並用實際的 regression 結果驗證。
